# Auto WebEtu — الحجز الجامعي الذكي (من برمجة Radwan Khedim)

## بناء APK
1. ثبّت Android Studio (Koala أو أحدث) وافتح مجلد المشروع؛ سيُنشئ Gradle Wrapper ويحمّل الاعتماديات.
2. Build ▸ Build APK(s) — الناتج: app/build/outputs/apk/debug/app-debug.apk
   أو من الطرفية: ./gradlew assembleDebug

## ⚠️ أهم خطوة قبل الاستخدام: مطابقة مسارات WebEtu
الملف WebEtuClient.kt (كائن Endpoints) يحوي مسار تسجيل الدخول المبني على واجهة PROGRES،
أما BOOK و RESERVATIONS فهما **افتراضيان وغير مؤكدين**. لتأكيدهما:
- شغّل تطبيق/موقع WebEtu الرسمي عبر أداة فحص حركة مرور (HTTP Toolkit / mitmproxy / Charles) على حسابك،
  نفّذ حجزاً يدوياً، وانسخ المسار وشكل الجسم (JSON) والرأس Authorization، ثم عدّل Endpoints ودالتي book/isReserved.
- إن كانت المنصة تفرض CAPTCHA عند الدخول فلن يتجاوزه التطبيق (حسب طلبك) وسيُبلغك بذلك.
- راجع شروط استخدام المنصة قبل الأتمتة.

إعدادات ▸ احفظ الحساب ▸ اختبار الدخول ▸ أدخل معرّف المطعم ▸ الرئيسية ▸ «حجز الآن (اختبار)» ▸ راجع السجل والإشعار.

## ملاحظات تشغيل
- WorkManager لا يضمن الدقة بالثانية؛ اضبط وقت الحجز قبل الموعد الأخير بهامش كافٍ (الافتراضي: 05:30 للغداء، 12:00 للعشاء).
- أوقف تحسين البطارية للتطبيق في بعض الهواتف (Xiaomi/Huawei/Oppo) كي لا تُقتل المهام.
- كلمة المرور مشفّرة بـ Android Keystore (AES-GCM)، ولا يتصل التطبيق إلا بـ progres.mesrs.dz.
